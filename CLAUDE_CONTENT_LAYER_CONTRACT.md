# CLAUDE_CONTENT_LAYER_CONTRACT

> Контент-слой white-label: фронт реализован, контракт на заморозку.
> Claude, 2026-07-04. Контекст: владелец заметил, что у чужого салона
> остаются фразы/слоганы МЭ — это был последний «зашитый» слой.

## 1. Что сделано на фронте (оба файла, за флагом saas-local)

Boot теперь читает **контент** салона и накладывает на `APP_DATA`:
`hero_tag`, `hero_title[≤3]`, `stats[[знач, подпись]…]`, `about[абзацы]`,
`ratings[[имя, оценка]…]`, `socials[]`.

Поведение:
- контент задан → главная показывает тексты салона;
- контент НЕ задан и салон ≠ МЭ → **нейтральные тексты** («Ваш салон.
  Ваше время.»), а виджеты «Статистика» и «Оценки» **скрываются**
  (не врём чужими цифрами «6+ лет · 98%»);
- МЭ без контента → всё как сегодня (паритет).

Проверено harness-тестами (3 сценария) + вживую на `demo-salon`.

## 2. Транспорт сейчас (работает без изменений бэка)

Фронт читает `cfg.content` **или** `cfg.branding.theme_json.content`.
Второй путь уже работает: контент «Гривы» задан текущим админ-API:
`PATCH /admin/tenants/:id/branding { themeJson: { ..., content: {...} } }`.

## 3. Запрос на заморозку контракта (формат §6)

1. Screen: главная клиентского PWA · Endpoint:
   `GET /mobile/config/:tenantSlug` · Current: контент доступен только
   в `branding.theme_json.content` · Desired: продвинуть в **top-level
   `content`** рядом с `brand` (форма ниже) · Non-blocking (фолбэк-чтение
   уже есть), но прошу зафиксировать до админки-UI.

```json
"content": {
  "hero_tag": "Добро пожаловать в «Гриву»",
  "hero_title": ["Грива.", "Стрижём так,", "что оборачиваются"],
  "stats": [["3", "года"], ["4", "мастера"], ["4.9", "рейтинг"]],
  "about": ["абзац 1", "абзац 2"],
  "ratings": [["Яндекс", "4.9"], ["2ГИС", "4.8"]],
  "socials": ["Telegram", "TikTok"]
}
```

2. Screen: онбординг салона · Endpoint: создание тенанта · Current:
   новый салон без контента получает нейтральные тексты (фронт-фолбэк) ·
   Desired: в будущей админке-UI поле «Тексты» обязательным шагом
   онбординга · Non-blocking.
